### ¿Qué encontrarás?

- 📊 Datos crudos y limpios importantes para la formulación, evaluación, estructuración y gestión de proyectos de inversión en el Perú.
- 🖥️ En **[www.inviertepe.com/data](https://www.inviertepe.com/data/)** hallarás los links de descarga directos y una sistematización de la data en razoń a sectores o tipologías de los proyectos.
- 🗺️ Datos geoespaciales: GeoJSON, GeoParquet y otros formatos.
- 📊 Información territorial y estadística.
- 🏗️ Datos e insumos para la formulación y evaluación de proyectos.
- 🤖 Recursos para análisis de datos
- ⚠️ Simpre revisar LEER_ES_BUENO <== Aquí se cita la fuente, diccionario de datos, referencias y otros datos importantes.
